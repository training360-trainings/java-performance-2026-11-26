# JVM performacia a felhőben és az AI világában

NETA.live webinár, 2026. 11. 26. // 18:00-19:00 // Viczián István

Tudod, mennyibe kerül futtatni a Java-alkalmazásod? A felhőben a memória és a CPU-idő is plusz költséget jelent, a JVM erőforrás-hatékonysága ezért üzleti kérdés. 
A következő NETAlive webináron megnézzük, hogyan hatnak a legújabb technológiák a Java-alkalmazások teljesítményére. Szó lesz a Leyden projektről, és kitekintünk a Valhalla value objectjeinek lehetőségeire is.
